# BlueShare knowledge base

Project knowledge for BlueShare, split into small linked files with one topic each (Open Knowledge Format v0.2). Start from a section index and open only the files the task needs. `log.md` records changes to this bundle.

## Sections

* [Product](product/index.md) - What BlueShare is, who it is for, the roadmap, the design sources and the known limitations.
* [Architecture](architecture/index.md) - Tech stack, folder structure, how the shell is put together and how routing works.
* [Design system](design-system/index.md) - Design tokens, light and dark palettes, sizes and the theme module that serves them.
* [Components](components/index.md) - One page per shell component: header, title field, footer tabs, create button, placeholder screen.
* [Decisions](decisions/index.md) - Technical decisions, with the alternatives that were rejected and why.
* [Specs](specs/index.md) - Capabilities already specified and implemented (app-shell, app-theming, app-platform).
* [Development](development/index.md) - Commands, Expo rules, dependencies, conventions, linting, testing, device checks and the OpenSpec workflow.
